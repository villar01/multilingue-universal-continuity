# Limites Operacionais: GitHub, Aplicativo Publicado e Execução Local

## Uso normal do aplicativo

O aplicativo publicado é usado no navegador. Alunos não precisam instalar GitHub, Copilot, modelos locais, GPU ou qualquer ferramenta de desenvolvimento. O acesso pedagógico continua submetido à autenticação, aos controles parentais e às regras de conteúdo do próprio aplicativo.

## Revisão externa por GitHub e Copilot

GitHub e GitHub Copilot servem apenas como apoio de leitura e revisão externa. Eles não substituem testes locais, não alteram arquivos automaticamente, não publicam mudanças e não tomam decisões pedagógicas, comerciais ou de segurança. Qualquer sugestão externa só pode ser aceita após revisão humana, testes e checkpoint.

## Execução local opcional

Hardware local, GPU e serviços de IA locais são opcionais para desenvolvimento ou experimentos técnicos. Eles não são requisito para alunos, não são iniciados automaticamente e não podem substituir a assistência integrada quando estiverem indisponíveis. Nenhum pagamento, instalação no dispositivo do cliente ou automação de vendas é ativado por esta orientação.

## Regra de alteração

Toda mudança segue o fluxo: alteração isolada, TypeScript, regressões aplicáveis, verificação funcional quando possível e checkpoint. Rotinas programadas, integrações, cobranças e ações comerciais exigem aprovação explícita antes de criação, reativação ou alteração.
