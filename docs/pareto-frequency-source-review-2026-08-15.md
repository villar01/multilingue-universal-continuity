# Revisão de fontes de frequência para o Pareto

Em 15 de agosto de 2026, foram consultadas duas referências públicas exclusivamente para avaliar possíveis critérios de frequência do complemento lexical do programa Pareto. Nenhuma lista externa foi copiada para o aplicativo.

| Fonte | Observação de licença e uso | Decisão no projeto |
|---|---|---|
| [first20hours/google-10000-english](https://github.com/first20hours/google-10000-english) | O próprio arquivo de licença limita os dados derivados do Google Web Trillion Word Corpus a uso educacional, pessoal ou de pesquisa e desaconselha uso comercial sem licença adicional. | **Não importar nem redistribuir** a lista. |
| [rspeer/wordfreq](https://github.com/rspeer/wordfreq) | O projeto declara Apache para o código e inclui dados com requisitos de atribuição/CC BY-SA e outras fontes. | **Não incorporar** dados nem derivar arquivo de palavras para o aplicativo sem cumprir a cadeia completa de atribuições e obrigações. |

O programa utilizará uma seleção lexical **autoral**, com termos, traduções, pronúncia figurativa e exemplos próprios. As fontes acima serviram apenas para confirmar que frequência não equivale a uma licença de republicação.
