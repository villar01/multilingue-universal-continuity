# Validação do aviso de GPU e interações visuais

| Verificação | Resultado |
| --- | --- |
| Guia inicial no desktop | Modal abre de forma legível, com diagnóstico de ausência de GPU NVIDIA, passos de preparação e rolagem disponível. |
| Guia inicial no celular | Página permanece responsiva; o conteúdo do guia pode ser percorrido sem exceder a largura da tela. |
| Comunicação de limites | O guia distingue IA de texto de animação facial, não promete aumento de GPU e não promete instalação automática. |
| Interações complexas | O aviso informa que recursos futuros dependem de GPU NVIDIA/CUDA, configuração e validação separadas. |
| Controle de privacidade | O guia afirma que não acessa arquivos pessoais. |

TypeScript e as regressões específicas do guia e aviso local foram aprovados antes desta verificação visual.
