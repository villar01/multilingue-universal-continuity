# Backup oficial do Manus — sequência segura

Este guia serve para preservar a conta e os dados do projeto afetado antes da data indicada na página oficial. **Exportar é apenas criar cópias. Não restaura, não apaga, não reinicia e não altera o aplicativo.**

## Antes de começar

Abra no seu navegador normal: <https://manus.im/backup>.

Use o mesmo método de entrada que já usa no Manus. Não envie senha, código de confirmação ou dados de login pelo chat.

## Etapa 1 — exportar os dados da conta

1. Entre na conta.
2. Na página **Backup & Restoration**, localize a seção **Export account data**.
3. Clique apenas em **Export** nessa seção.
4. Aguarde o navegador concluir o download do arquivo de conta.
5. Confirme que o arquivo foi salvo. Não renomeie, não abra e não altere o arquivo.

Pare aqui antes de fazer a próxima etapa.

## Etapa 2 — exportar os dados das tarefas

1. Na mesma página, localize a seção **Export task data**.
2. Clique apenas em **Export** nessa seção.
3. Para a cópia mais ampla, escolha **Export more → All tasks → All time → Start export**.
4. Aguarde o download dos arquivos de tarefa.
5. Confirme que todos os arquivos foram salvos no mesmo local seguro, sem renomeá-los ou misturá-los com arquivos de outra exportação.

## Conferência final

Guarde juntos os arquivos da conta e das tarefas em local seguro. A exportação é uma fotografia do momento em que foi criada; mudanças posteriores não entram nela. Para um site em uso, faça uma nova exportação perto do prazo oficial e mantenha todas as cópias completas.

> **Não clique em Restore, não envie nenhum arquivo de volta ao Manus e não exclua arquivos exportados.** A restauração é uma operação futura e separada.
