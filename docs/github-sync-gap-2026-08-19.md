## Regra de envio

Nenhum `push` foi executado durante esta verificação. Antes de qualquer envio, a comparação deve ser repetida e o titular deve confirmar o envio dos commits locais ao repositório privado conectado. A confirmação é necessária porque o envio altera uma cópia externa, embora o repositório seja privado.
