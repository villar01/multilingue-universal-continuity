# Evidência de ordem gramatical por idioma

## Regra de escopo

O currículo não deve reutilizar automaticamente a ordem do português ou do inglês para outro idioma. Cada modelo de frase deve declarar o idioma-alvo, o padrão introdutório usado e os casos que exigem uma regra própria.

## Evidência inicial para os idiomas comerciais

| Idioma | Orientação introdutória comprovada | Limite que deve permanecer explícito |
| --- | --- | --- |
| Inglês | Frases básicas geralmente usam sujeito + verbo + objeto. | Perguntas e negativas mudam a posição ou usam auxiliares. |
| Espanhol | Frases básicas podem partir de sujeito + verbo + objeto. | A flexão verbal e a omissão do sujeito exigem exemplos próprios. |
| Francês | Frases básicas podem partir de sujeito + verbo + objeto. | Perguntas, negação e colocação de pronomes não devem copiar o inglês. |
| Italiano | Frases básicas podem partir de sujeito + verbo + objeto. | A omissão do sujeito e a flexão verbal precisam de prática própria. |
| Alemão | A frase declarativa introdutória pode usar sujeito + verbo + complemento, com verbo conjugado na segunda posição. | Inversão, perguntas, subordinadas e verbos separáveis exigem modelos próprios. |

As fontes pedagógicas consultadas confirmam SVO como fórmula introdutória para inglês, espanhol, francês e italiano, mas tratam alemão como ordem mais flexível e dependente da posição verbal. Portanto, esta nota autoriza somente a modelagem inicial explícita; não autoriza extrapolar a mesma ordem para perguntas, negativas, subordinadas ou todos os 143 idiomas.

## Próximo contrato de código

A futura entrega multilíngue deverá anexar um identificador de idioma e um `sentenceOrderProfile` a cada prática. O perfil deverá ser testado por idioma antes de habilitar geração de exercício. Até esse contrato existir, o currículo PT-BR → inglês continua protegido por regressão própria e a tarefa de cobertura completa por idioma permanece aberta.
